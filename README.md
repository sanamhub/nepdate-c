# nepdate-c

Bikram Sambat (Nepali calendar) dates for C: conversion to and from the Gregorian calendar,
arithmetic, formatting and parsing, with no allocation and no dependencies.

**Status: in development. Nothing is released yet.** The C++, Rust, Go, TypeScript, Python, Swift
and Kotlin ports are released; see [nepdate.com](https://nepdate.com).

# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Report privately through
[GitHub security advisories](https://github.com/sanamhub/nepdate-c/security/advisories/new).
Do not open a public issue.

Include the input that triggers it, the platform and the package version. Expect a first reply
within a week.

A wrong calendar result, where nepdate-c and the shared data give the same wrong answer, belongs
to the hub: [sanamhub/nepdate security policy](https://github.com/sanamhub/nepdate/security/policy).
